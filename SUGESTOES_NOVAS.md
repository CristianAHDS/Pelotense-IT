# Sugestões de Features Futuras - Pelotense IT

## 🔮 Features Avançadas

### Automação
| Feature | Descrição |
|---------|-----------|
| Regras automáticas | Configurar ações automáticas: "se prioridade crítica, notificar todos os técnicos" |
| Escalonamento | Reatribuir chamados automaticamente se não respondidos em X horas |
| Lembretes | Agendar lembretes para follow-up em chamados parados |
| Fechamento automático | Fechar chamados sem atividade por 30 dias |

### Portal do Cliente
| Feature | Descrição |
|---------|-----------|
| Portal público | Interface separada para solicitantes acompanharem seus chamados |
| Auto-cadastro | Usuários podem se cadastrar e abrir chamados sem intervenção |
| Base de conhecimento | Artigos e FAQs para auto-resolução antes de abrir chamado |
| Pesquisa de satisfação | NPS (Net Promoter Score) ao fechar chamado |

### Dashboard & BI
| Feature | Descrição |
|---------|-----------|
| Mapas de calor | Visualização geográfica de chamados por localidade |
| Previsão | Machine learning para prever picos de chamados |
| Comparativos | Comparar períodos (este mês vs mês passado) |
| Alertas inteligentes | Detectar anomalias: "15% mais chamados que a média" |

### Colaboração
| Feature | Descrição |
|---------|-----------|
| Times | Agrupar técnicos em times (Redes, Suporte, Infra) |
| Transferência | Transferir chamado entre técnicos com justificativa |
| Aprovações | Fluxo de aprovação para chamados que exigem autorização |
| @menções | Marcar colegas nos comentários com notificação |

### Mobile
| Feature | Descrição |
|---------|-----------|
| App nativo | Build Tauri para Windows/Mac/Linux |
| QR Code | Gerar QR code do chamado para acesso rápido |
| Biometria | Login por digital/Face ID no app |
| Offline first | Funcionar sem internet e sincronizar depois |

### Integrações
| Feature | Descrição |
|---------|-----------|
| Slack/Teams | Bot que cria/atualiza chamados via chat |
| Active Directory | Sincronizar usuários e autenticação com AD |
| E-mail (IMAP) | Criar chamados automaticamente a partir de e-mails |
| Calendário | Integrar com Google/Outlook para agendamento |
| API pública | Documentação Swagger para integrações externas |

### Segurança
| Feature | Descrição |
|---------|-----------|
| 2FA | Autenticação de dois fatores |
| Log de auditoria | Registro de todas as ações para compliance |
| Criptografia | Dados sensíveis criptografados em repouso |
| Rate limiting | Proteção contra abuso da API |

## 📊 Relatórios - Melhorias Futuras

- **Agendamento**: programar geração automática de relatórios (diário/semanal/mensal) e envio por e-mail
- **Dashboard executivo**: página separada com KPIs de alto nível para gestores
- **Gráfico de pizza**: visualização de proporção entre categorias
- **Exportar gráfico como imagem**: botão para salvar gráfico como PNG
- **Filtros avançados**: combinar múltiplos filtros (status + prioridade + técnico + período)
- **Drill-down**: clicar em um item do gráfico para ver os chamados que o compõem
